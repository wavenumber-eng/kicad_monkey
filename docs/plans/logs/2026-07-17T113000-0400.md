# Log: durable-design-doc-updates

Implemented the selected documentation-only direction from
`api-design-decision`.

## Updated durable artifacts

- `README.md` now includes large-file scan guidance for
  `KiCadPcbProjection` and `iter_kicad_objects_from_file`, plus the read-path
  decision model for full model, projection, targeted reader, and render APIs.
- `docs/design/api/pcb-api.html` documents the full-model cost of
  `KiCadPcb.from_file`, `to_ir()`, and `to_svg()`, and documents that
  `layers=` filters emitted SVG records after full IR construction.
- `docs/design/api/project-design-api.html` documents lazy PCB loading in
  `KiCadDesign` and explains that design-level PCB rendering still becomes a
  full-board render path once board data is touched.

  section for `iter_kicad_objects_from_file` and
  `iter_kicad_objects_from_text`, including schematic narrow-read guidance and
  explicit deferral of a named `KiCadSchematicProjection` facade.
- `docs/requirements/2026-07-17-performance-optimization-requirements.html`
  restores durable PERF-REQ-008 external-review evidence with the fresh
  Jumperless decomposition numbers and the materialization-floor conclusion.
- `docs/releases/2026-07-17.md` and `CHANGELOG.md` now include the project/API
  guidance work and no longer say that guidance is deferred.

## Closed by reviewed rejection

No file-level IR/SVG helper API was added. The reviewed decision rejects that
candidate for this plan because the current renderer requires full-board
semantics for bounding boxes, draw order, layer filtering, enrichment metadata,
and stable output. The `file-level-ir-svg-api-implementation` step is therefore
closed by documented rejection, not by code implementation.

No public render cache API, inventory-helper wrapper, pull parser, or native
extension was added. Those remain deferred exactly as recorded in the decision
log.
