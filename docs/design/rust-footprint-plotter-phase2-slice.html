Rust Phase 2 Footprint Plotter-IR Slice

Decision

The first bytes-to-plotter proof promotes standalone-footprint metadata and solid fp_line geometry. It emits a strict TypeSpec-owned subset of the established kicad.plotter_ir.a0 document. This slice proves the boundary and does not claim parity for dashed lines, text, properties, arcs, circles, rectangles, polygons, pads, symbols, or embedded PCB footprints.

Architecture

  • FootprintView first enforces one standalone footprint root. The plotter reader then selects only exact top-level metadata and fp_line spans. It parses those small forms independently and never constructs a generic tree for the complete file.
  • Coordinates cross the boundary as integer nanometres with Y down. Conversion uses ties-to-even rounding and the same default, negative, and minimum-pen-width rules as the Python path.
  • Output order follows source order. Unsupported stroke styles are explicit model diagnostics; they are not silently rendered as solid.
  • Source bytes, nesting depth, operation count, and serialized output bytes are caller bounded. The JSON writer stops at the output limit instead of first allocating an unbounded result.

Contract And WASM Boundary

TypeSpec owns the request, result metadata, and initial document subset. Generated Rust, Python, and TypeScript types stay deterministic. Browser callers pass KiCad and request bytes separately to plotFootprintIr. The operation returns result JSON and plotter-IR JSON as separate byte arrays, avoiding base64 and preserving a resource-limit diagnostic envelope.

Parity Evidence

Rack L1_026 makes Python and Rust consume one shared vector and requires the exact same document. It validates that document against both the strict generated slice schema and the established plotter-IR schema. Rack L0_046 owns real Node-hosted WASM execution and Rust quality; L0_049 owns generated-language cleanliness.

Retained Work

Expand TypeSpec to the full plotter operation union, then promote dashed lines, remaining footprint graphics, pads, text, and symbol output with independent parity vectors. The Phase 2 boundary review remains gated on that wider proof. Performance tuning remains profile-driven.
