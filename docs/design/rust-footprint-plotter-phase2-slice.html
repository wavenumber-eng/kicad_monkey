Rust Phase 2 Footprint Plotter-IR Slice

Decision

The footprint bytes-to-plotter proof now promotes standalone-footprint metadata, lines, three-point arcs, circles, rectangles, and polygons. Patterned line and arc strokes are decomposed into thick segments using the Python path's dash rules. It emits a strict TypeSpec-owned subset of the established kicad.plotter_ir.a0 document. This slice does not claim parity for text, properties, pads, symbols, or embedded PCB footprints.

Architecture

  • FootprintView first enforces one standalone footprint root. The plotter reader then selects only exact top-level metadata and supported graphic spans. It parses those small forms independently and never constructs a generic tree for the complete file.
  • Coordinates cross the boundary as integer nanometres with Y down. Conversion uses ties-to-even rounding and the same default, negative, and minimum-pen-width rules as the Python path.
  • Output order follows Python's canonical grouping: lines, arcs, circles, rectangles, then polygons. Source order is retained within each group. Solid/default strokes remain native operations; dash, dot, dash-dot, and dash-dot-dot strokes are deterministically decomposed.
  • Source bytes, nesting depth, metadata-form count, operation count, and serialized output bytes are independently caller bounded. Metadata duplicates therefore cannot consume the geometry allowance. The JSON writer stops at the output limit instead of first allocating an unbounded result.

Contract And WASM Boundary

TypeSpec owns the request, result metadata, exact two-coordinate polygon points, fill vocabulary, and tagged graphic-operation union. Generated Rust, Python, and TypeScript types stay deterministic. Browser callers pass KiCad and request bytes separately to plotFootprintIr. The operation returns result JSON and plotter-IR JSON as separate byte arrays, avoiding base64 and preserving a resource-limit diagnostic envelope.

Every numeric document field declared as a JavaScript-safe integer is bounded to ±9,007,199,254,740,991 in JSON Schema. Native conversion and the generated Rust and Python transport types enforce the same range so an out-of-range integer cannot silently lose precision in JavaScript.

Parity Evidence

An interleaved input proves canonical grouping, and the corpus covers patterned line/arc decomposition plus every promoted operation and fill. Documents validate against both the strict generated slice schema and the established plotter-IR schema.
