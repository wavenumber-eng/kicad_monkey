# KiCad Monkey 2026.8.31

Release version: `2026.8.31`

Date: 2026-08-31

This release accelerates the native Rust S-expression implementation without
changing its public parser, projection, resource-limit, diagnostic, native,
streaming, or WASM contracts.

The lexer now scans structural ASCII and token runs by byte while preserving
exact Unicode-scalar positions. Sparse projection borrows unquoted in-memory
heads, derives paths from the active frame stack, and materializes owned heads
and paths only for selected forms. Streaming projection eliminates path
cloning while retaining only the active owned heads required across chunks.

On the accepted same-host evidence, lexer throughput improved 2.30x. Sparse
in-memory and streaming scans improved 5.05x and 2.74x, while their allocated
bytes fell 99.90% and 96.39%. The complete native Speedy design-review median
improved from 7.618 seconds to 5.028 seconds, with all 35 report artifacts and
29 SVGs retaining semantic parity.

Validation includes shared Python/Rust memory, stream, and StructuralIndex
vectors; exact resource boundaries; malformed, quoted, escaped, Unicode,
headless, pruning, teardrop, and 64-KiB streaming cases; full locked Rust
tests; corpus roundtrip and determinism; real Node-hosted WASM; Cruncher
consumer gates; and independent architecture, implementation, evidence, and
test-coverage review.
