# KiCad Monkey 2026.9.2

Release version: `2026.9.2`

Date: 2026-09-02

This release repairs reopened issue #78 in the direct typed Rust SVG surface.
Footprint, symbol, board, and schematic SVGs now serialize dimensions in the
browser-visible millimetre coordinate space while retaining exact nanometre
viewport and bounds metadata in the Rust API. Native a0 transport bytes remain
compatible.

Fitted viewports retain uncached text with bounded estimates, including
non-square font dimensions and authored text mirroring. The MIMXRT685SFVKB
symbol and all four direct-render families pass Chromium coverage, with WebKit
coverage for the high-risk symbol case. Production Cruncher schematic and PCB
review artifacts and an external pinned-Git consumer exercise the same public
renderers and validated context overrides without Python, WASM, JSON
reconciliation, or a native sidecar in the rendering path.

Alexandria independently pinned the reviewed commit and rendered all four file
families in Chromium and WebKit. Its live preview workflow loaded 10,604 parts
and displayed the formerly broken MIMX symbol with its body, text, pin names,
and pin numbers. Standalone footprint pad-number identity remains outside the
frozen `FootprintPlotDocumentA0` contract and is documented as a future
versioned-contract concern rather than a regression in this release.
