# KiCad Monkey 2026.8.16.1 And 2026.8.16

## 2026.8.16.1

Release version: `2026.8.16.1`

Date: 2026-08-16

This patch release removes two repeated whole-board lookup patterns from PCB
Plotter-IR conversion. One immutable net-table snapshot resolves all element
net references, and one project netclass mapping enriches every record and pad.
One-off board lookup remains behaviorally unchanged, and mutable boards require
callers to request a new explicit snapshot after changing the net table.

On the 17 MB Speedy Processing Module board, five measured conversions after
one warm-up produced medians of 3.01 seconds with 2026.8.16 and 1.27 seconds
with 2026.8.16.1, a 57.9 percent reduction. Canonical 24,024,934-byte IR JSON
was byte-identical by SHA-256
(`02f06e430f24fbb93513809f1baa88ad6c54d16571774770d9bb69a176c563f9`). A
separate uncontended optimized run completed in 0.98 seconds. On a synthetic
1,388-net, 30,373-reference workload matching issue #24, explicit snapshot
lookup was 523x faster and returned identical names.

## 2026.8.16

Release version: `2026.8.16`

Date: 2026-08-16

This release reduces the cost of parsing large KiCad schematic and board files
without changing the public token, tree, design, PCB, or projection contracts.

## Highlights

- Lex S-expressions with a single-pass regular-expression scan instead of
  restarting an anchored match at every token boundary.
- Resolve token line and column positions lazily from source offsets while
  retaining exact structured diagnostics.
- Build ordinary S-expression trees iteratively while preserving the
  specialized recursive path for legacy teardrop forms.
- Preserve frozen `SexpToken` construction, separator whitespace round trips,
  CR/LF/CRLF handling, and whole-line comment behavior.
- Match KiCad's insertion order for non-primary multi-unit component timestamps.
- Cover restored power-port parent-symbol links in compiled-graph corpus goldens.

## Performance

On the current 17 MB Speedy Processing Module board, alternating full
`KiCadPcb.from_file()` runs against pristine current `main` improved from a
10.73 second median to 8.95 seconds, about 1.20x faster with identical parsed
object counts.

## Validation

- Complete public Rack suite across all available strata.
- Parser compatibility and round-trip tests, including malformed input,
  source locations, separators, comments, teardrops, and deep trees.
- Current Speedy board parsing with identical footprint, route, via, arc, and
  zone counts before and after the change.
