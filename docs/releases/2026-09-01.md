# KiCad Monkey 2026.9.1

Release version: `2026.9.1`

Date: 2026-09-01

This release adds a native linked-library Rust path from typed Plotter-IR to
SVG for footprints, symbols, boards, and concrete schematic-page occurrences.
Consumers such as Alexandria can pin one exact Git revision and generate SVG
previews without WASM, JSON reconciliation, Python, or a native sidecar in the
rendering path.

Every direct renderer accepts the same bounded, validated context for layer
selection, raw-color remapping, semantic/layer/operation style overrides,
visibility, pin-name and pin-number policy, identity emission, fonts,
backgrounds, and explicit or fitted viewports. Board artifacts carry an
atomically paired enabled-layer catalog and copper stack; schematic-page
artifacts retain their occurrence address without widening the frozen wire
contracts.

The existing native request remains byte-compatible across all 29 successful
frozen SVG vectors. Validation includes synthetic four-family fixtures, exact
limits and structured errors, transformed fit bounds, physical pad/via/drill
behavior on the governed Yoshi board, real native and WASM compatibility,
Cruncher cross-package consumption, an exact pinned-Git Cargo consumer, full
locked workspace tests, warning-denied Clippy, performance baselines, and
independent architecture, implementation, resource, and test review.
