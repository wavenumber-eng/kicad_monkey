# 2026-06-15 Release

Release version: `2026.6.15`

This release adds KiCad library extraction and project asset scanning support
for downstream project-local library and library-ingestion workflows.

## Notes

- Adds symbol, footprint, metadata, and STEP model extraction helpers for
  project-local library generation.
- Adds cleaned extraction support for downstream library ingestion workflows
  where reusable CAD assets are separated from instance metadata.
- Adds project asset scanning for embedded and external 3D model references.
- Optimizes large-project extraction by isolating relevant S-expression blocks
  before building KiCad model objects.
- Keeps KiCad CLI validation helpers for generated symbol and footprint
  libraries.
