# 2026-07-16 Alpha Release Candidate

Release version: `2026.7.16a0`

This candidate adds a documented KiCad Plotter IR contract, carries schematic
hyperlink metadata through the IR context mechanism, removes profile-specific
preference setup assumptions, and preserves the design JSON contract while
reducing repeated pin-count work.

## Notes

- Adds `docs/contracts/kicad_plotter_ir_a0.schema.json` as the JSON Schema for
  serialized Plotter IR documents emitted by `kicad_monkey`.
- Adds the accepted `docs/design/kicad-plotter-ir.html` reference covering IR
  document fields, records, operation payloads, units, context extension
  rules, validation guidance, and consumer compatibility expectations.
- Emits `schema = "kicad.plotter_ir.a0"` for new Plotter IR documents while
  retaining reader compatibility with the previous `kicad.plotter_ir.v1`
  schema string.
- Preserves KiCad schematic text `href` metadata as
  `context.hyperlink.href` on text operations without requiring SVG renderers
  or geometry consumers to understand hyperlink context.
- Makes `setup_kicad_preferences(preferences_source=...)` merge supported
  KiCad preference JSON files directly from the supplied source directory,
  including `kicad_common.json`, `eeschema.json`, `pcbnew.json`,
  `fpedit.json`, `pl_editor.json`, and `gerbview.json`.
- Copies color theme files and logs source-derived theme/settings names without
  embedding profile-specific assumptions in `kicad_monkey`.
- Removes profile-specific runtime defaults from KiCad setup/library helper
  paths; callers that need named profiles now provide those names explicitly.
- Replaces per-component terminal rescans in design JSON generation with a
  one-pass pin-count index while preserving duplicate, empty-pin, disconnected,
  and case-sensitive reference behavior.
- Aligns release signoff with the configured dev-std audit scopes and keeps
  developer planning files excluded from source distributions.
