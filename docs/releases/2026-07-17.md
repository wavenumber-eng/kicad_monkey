# 2026-07-17 Release

Release version: `2026.7.17`

This release improves large-board PCB parse and projection performance while
preserving parser, projection, source-span, and net-reference behavior. It also
adds a canonical workflow guide for choosing full-model, projection,
targeted-reader, project, IR, and SVG APIs. The work addresses the performance
reports in GitHub issues #16 and #17; public PRs #18 and #19 were used as
research inputs only.

## Notes

- Reworks S-expression lexing with a compiled pure-Python regex tokenizer,
  grouped numeric token classification, and lazy quoted-string unescape,
  without adding native dependencies or changing the public token/span
  contracts.
- Adds source line-column indexing for nested PCB projection source-span
  rebasing while preserving exact offsets, source text, and reparsed
  S-expression behavior.
- Caches direct child spans per parent during projection hydration so pad and
  model reference scans do not repeatedly walk the same footprint source text.
- Reuses PCB net lookup maps in full parse and projection paths while
  preserving KiCad v10 name-only net references when no top-level net table is
  present.
- Records final three-round performance evidence in
  `docs/requirements/2026-07-17-performance-optimization-requirements.html`.
- Records mixed full-parse results honestly: projection hydration improves
  further after the regex rewrite, while token object and generic tree
  materialization keep the earlier 3-8x full-parse expectation unproven.
- Adds project/API guidance for choosing between full materialization,
  `KiCadPcbProjection`, targeted readers, and render APIs; documents that PCB
  render `layers=` filters output after full IR construction. The
  user-facing workflow guide is
  `docs/guides/project-workflows.html`.
- Treats public PRs #18 and #19 only as research inputs; the implementation is
  independently rewritten on the performance branch.
- Defers file-level IR/SVG partial API design and C/C++/Cython tokenizer or
  parser acceleration implementation to follow-on work.
