# KiCad Monkey 2026.8.17

Release version: `2026.8.17`

Date: 2026-08-17

This release removes two repeated whole-board lookup patterns from PCB
Plotter-IR conversion. One immutable net-table snapshot resolves all element
net references, and one project netclass mapping enriches every record and pad.
Mutable boards require callers to request a new explicit snapshot after changing
the net table. Legacy one-off board resolution retains its direct implementation
and does not construct or freeze a snapshot for each call.

On the 17 MB Speedy Processing Module board, five measured conversions after
one warm-up produced medians of 3.01 seconds with 2026.8.16 and 1.27 seconds
with the optimized candidate, a 57.9 percent reduction. Canonical 24,024,934-byte
IR JSON was byte-identical by SHA-256
(`02f06e430f24fbb93513809f1baa88ad6c54d16571774770d9bb69a176c563f9`). A
separate uncontended optimized run completed in 0.98 seconds. On a synthetic
1,388-net, 30,373-reference workload matching issue #24, explicit snapshot
lookup was 523x faster and returned identical names.

Validation covers the complete public Rack suite, release-signoff contracts,
static analysis, package builds, downstream artifact equivalence, and explicit
tests that distinguish the one-off and bulk lookup paths.
