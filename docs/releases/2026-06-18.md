# 2026-06-18 Release

Release version: `2026.6.18`

This release hardens the library extraction and targeted parsing surfaces used
for project-local library generation, design review, and downstream library
ingestion workflows.

## Notes

- Adds a generic targeted KiCad object reader for iterating selected typed
  objects from schematic, symbol, board, and footprint files.
- Moves symbol and footprint extraction helpers onto the targeted reader API
  while keeping object-level return contracts.
- Adds reusable parameter alias normalization for canonical component metadata.
- Fixes hidden graphical symbol text output so generated symbol libraries pass
  current KiCad CLI validation.
- Promotes the 4-channel backplane and synthetic hierarchy fixtures through
  parser, netlist, board SVG, schematic SVG, and IR regression gates.
