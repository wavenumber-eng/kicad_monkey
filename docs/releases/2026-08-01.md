# 2026-08-01 Release

Release version: `2026.8.1`

This patch release fixes zone fill emission so boards written by kicad-monkey
with unfilled copper zones load in KiCad.

## Notes

- Unfilled copper zones now emit a bare `(fill ...)` element instead of
  `(fill no ...)`. KiCad's parser accepts only a bare `yes` token inside a
  zone `fill` element, so boards written with the old form failed to load
  ("Failed to load board").
- The emitted form matches KiCad's own writer, which appends `yes` only when
  a zone is filled.
- Parsing is unchanged; legacy files carrying `(fill no ...)` are repaired on
  re-emit.
- Keepout zones and graphics shapes are unaffected; `(fill no)` remains valid
  for shapes.

## Validation

- New `tests/L1_parsing/test_L1_021_zone_fill_emission.py` covering emission
  rules, round-trip preservation of both KiCad spellings, and legacy
  `(fill no ...)` normalization.
- New kicad-cli oracle gate case forcing unfilled copper zones on the
  `LayerWildcard` fixture and requiring `kicad-cli pcb upgrade --force` to
  accept the emitted board.
- Full local test sweep across L0-L4 strata green on Windows.
