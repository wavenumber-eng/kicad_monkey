# KiCad Monkey 2026.8.10.1

Release version: `2026.8.10.1`

Date: 2026-08-10

This patch release restores power-symbol net activation for compiled-graph
schematic viewers. Visible power-symbol groups now carry scoped drawing links
to their `power_port` terminals, including symbols whose electrical pin is
hidden or zero-length.

## Validation

- Package-local compiled-graph and release-signoff gates.
- Speedy cross-package coverage for all 332 power terminals and a real
  power-symbol click through the retained-scene activation path.

## Prior release: 2026.8.10

Release version: `2026.8.10`

Date: 2026-08-10

This release gives enriched schematic SVG consumers a validated,
page-occurrence-scoped navigation view over the compiled schematic graph.
Non-rendered pin evidence is no longer advertised as an SVG selector, and
overplot rendering no longer duplicates canonical primary pin ids.

## Highlights

- Export deterministic forward and reverse indexes between rendered schematic
  SVG elements and occurrence-scoped compiled-graph drawing links.
- Resolve graph views through canonical page occurrences, including repeated
  and nested reused hierarchy.
- Validate every advertised SVG selector against the final serialized SVG.
- Preserve component, terminal, local-net, hierarchy, and binding identities
  while correcting drawing-only evidence.

## Validation

- Package-local L0 and L99 Rack gates.
- Real-project selector audits for Taillight, Yoshi, and Speedy.
- Cross-package source and clean installed-wheel compatibility with KiCad
  Cruncher.
- Linux and Windows CI, package build, Twine, and upgrade/rollback rehearsal.
