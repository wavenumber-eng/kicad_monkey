# 2026-06-19 Release

Release version: `2026.6.19`

This release fixes PCB graphical source-model bounds and adds a direct KiCad
oracle path for proving numerical correctness.

## Notes

- Adds shape-specific `KiCadPcb.get_bounds()` support for board graphical
  lines, rectangles, circles, arcs, polygons, and Bezier curves.
- Compares graphical bounds against KiCad's bbox behavior through analytic
  tests and a patched `kicad-cli pcb export bbox` oracle.
- Stages and restores the bbox-capable KiCad CLI bundle through the
  `tools/kicad-cli` manifest and R2 cache metadata.
- Routes `KiCadPcb.to_svg()` through the plotter IR renderer and removes the
  old direct `to_svg_elements()` renderer surface.
- Keeps the 4-channel backplane fixture covered by package-local corpus bounds
  and rendering regression tests.
