# 2026-08-09 Release

Release version: `2026.8.9`

This release adds the KiCad Newstroke webfont bundle and exposes the
occurrence-scoped compiled schematic graph used by downstream schematic
visualization.

## Notes

- Extend the bundled CC0 Newstroke data through U+2BFF and package Light,
  Regular, Bold, and italic webfont faces with CSS and a blue phosphor demo.
- Export reusable schematic definitions, realized hierarchy, component and
  terminal occurrences, local nets, hierarchy bindings, and scoped drawing
  evidence from `KiCadDesign.to_json()`.
- Keep canonical identities stable across reused hierarchy occurrences,
  endpoint renames, collection reordering, and drawing-only UUID changes.
- Render schematic directives, rule areas, and DNP hierarchical sheets through
  Plotter IR while preserving source identity.
- Preserve inherited BOM, board, DNP, and simulation policy across the complete
  schematic occurrence tree.
- Match KiCad CLI root-sheet metadata and multi-unit timestamp ordering for the
  affected netlist cases.

## Validation

- Compiled-graph acceptance covers real reused-sheet, multipart, hierarchy,
  global-label, bus, and bus-entry cases plus adversarial identity and reference
  mutations.
- Package-local Rack signoff verifies version metadata, public documentation,
  quality ratchets, and generated webfont assets.
- Cross-package tests exercise both the released dependency lane and the live
  embedded compiled-graph producer before downstream cutover.
