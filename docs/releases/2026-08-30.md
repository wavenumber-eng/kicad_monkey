# KiCad Monkey 2026.8.30

Release version: `2026.8.30`

Date: 2026-08-30

This release implements KiCad's unused-copper-layer policy for plated pads and
vias in both the Python and Rust source models. Round-trip parsing preserves
`remove_unused_layers`, `keep_end_layers`, and `start_end_only`, while board
layer resolution follows KiCad's per-layer flashing and conditional
connectivity behavior.

Plotter-IR, SVG rendering, zone filling, and bounds now distinguish optional
copper apertures from mandatory physical holes. Pad drill offsets move copper
lands without moving the drilled hole, and plated pad drills retain their
through-board scope independently of authored copper membership.

Validation includes synthetic connectivity and geometry cases, shared
Python/Rust parity vectors, the reviewed Yoshi corpus, native SVG consumers,
and the cross-package KiCad Cruncher STEP and PCB review workflows.

The release also adds KiCad 10 project-level schematic bus aliases. KiCad 9
and older files may still declare `(bus_alias ...)` in `.kicad_sch`; KiCad 10
stores the design-wide map at `schematic.bus_aliases` in `.kicad_pro`. For that
project map, Monkey trims alias names and members, discards blank/non-string entries, preserves
member order and duplicates, and retains valid aliases with no surviving
members. Project definitions override same-name legacy definitions, including
empty definitions, while unrelated legacy aliases remain visible. For
malformed project JSON whose distinct keys collide only after trimming,
Monkey deterministically keeps the last encountered project entry. Legacy
schematic aliases retain their existing source-model behavior rather than
being rewritten by the KiCad 10 project normalization policy.

Python and Rust apply the same effective alias map to scalar netlists,
version-E export, compiled schematic graphs, Design JSON, and Cruncher-facing
native facts. The project-authored `project_bus_alias_hierarchy` fixture is
reviewed against KiCad CLI 10.0.5 and uses actual buses, entries, member labels,
and a hierarchical sheet boundary; the upstream KiCad GPL fixture remains a
local research reference and is not copied into the distribution.
