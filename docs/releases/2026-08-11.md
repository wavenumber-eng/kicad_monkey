# KiCad Monkey 2026.8.11.1

Release version: `2026.8.11.1`

Date: 2026-08-11

This patch release separates Altium-import cleanup from optional Fab outline
generation and hardens embedded-model normalization.

## Highlights

- Remove imported Fab/User content without generating a STEP-derived F.Fab
  projection or pad/silkscreen convex hull.
- Keep one actual embedded STEP payload and rename it to a footprint-scoped
  `.STEP` name, even when its incoming extension is `.SLDPRT`.
- Drop genuine SolidWorks, Parasolid, and unknown embedded model payloads with
  warnings because no proprietary-to-STEP conversion is available.
- Prefer the STEP model already named for the footprint when an import contains
  multiple model bodies, preserving that model record's KiCad transform.

## Validation

- Focused filter tests for model content detection, canonical naming,
  unsupported payloads, multiple STEP models, and Zstandard streaming frames.
- Cross-package Altium conversion coverage proving Cruncher uses the
  import-specific cleanup entry point.

## Prior release: 2026.8.11

Release version: `2026.8.11`

Date: 2026-08-11

This release hardens KiCad footprint compatibility at the parser/source-model
boundary and removes the application-specific Part conversion workflow from
Monkey.

## Highlights

- Normalize unsafe direct pad sizes to KiCad's 0.001 mm compatibility value.
- Preserve valid nested custom-pad primitive sizes and all pad identities,
  drills, kinds, and layers.
- Return structured normalization diagnostics and retain the legacy zero-pad
  filter as a compatibility wrapper.
- Produce a universal pure-Python wheel and validate the full suite on Python
  3.14 under Windows and Linux CI.

## Validation

- Focused pad-kind, one-axis, negative, nested-size, malformed-input, and
  idempotence coverage.
- KiCad 10.0.5 source and CLI behavior comparison.
- Monkey release-signoff and interface-design gates.
