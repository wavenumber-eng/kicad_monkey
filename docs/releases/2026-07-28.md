# 2026-07-28 Release

Release version: `2026.7.28`

This patch release hardens project-local library extraction for KiCad projects
that contain editor history, autosave, or backup folders next to active design
files.

## Notes

- Ignores KiCad `.history`, autosave, and backup-style directories during
  project-local file discovery.
- Traverses the active schematic hierarchy from the project root sheet instead
  of recursively scanning orphan schematics.
- Uses the active project-stem board for PCB extraction and asset inventory.
- Exposes deterministic symbol and footprint output-member maps for downstream
  source relinking workflows.
- Preserves duplicate footprint member naming, including generated `_2`
  suffixes, when producing relink maps.
