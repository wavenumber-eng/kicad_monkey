# KiCad Monkey 2026.8.22

Release version: `2026.8.22`

Date: 2026-08-22

This release publishes the completed Windows x64 native application work that
followed the last public `2026.8.17` package. The wheel includes the bounded
native design-facts and SVG providers used by KiCad Cruncher, while Linux and
macOS retain the Python provider path.

The native transport now covers source-bound compiled schematic graphs,
deterministic version-E netlists, and base SVG with explicit resource limits,
source identity, and transactional output guarantees. The date-versioned Rust
workspace and Python distribution are released from the same reviewed source
commit at `2026.8.22`.

Validation covers the generated Rust/Python/TypeScript contracts, reviewed
KiCad corpora, Python/native differential tests, installed Windows-wheel
execution, native artifact provenance, and the coordinated public Monkey and
Cruncher install path.
