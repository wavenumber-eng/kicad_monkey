# 2026-06-25 Release

Release version: `2026.6.25`

This release adds the object-model primitives for scaffolding a new KiCad
project while preserving public constructor compatibility. All construction
lives in `kicad_monkey`; higher-level applications gather input and compose
these primitives.

## Notes

- Grows `KiCadProject` into a small new-project aggregate through
  `KiCadProject.create(name, directory)`, with `add_schematic`,
  `set_worksheet`, `add_pcb`, `add_symbol_library`, `add_footprint_library`,
  `ensure_library_tables`, and `write_project`.
- Adds ADR-008 and updates design docs to make the public construction rule
  explicit: `from_*` loads existing material, `new` creates one blank
  KiCad-valid document, and `create` starts a higher-level aggregate workflow.
- Adds `EmbeddedFile.from_worksheet` and `KiCadSchematic.embed_worksheet` for
  packing `.wks` drawing sheets (zstd + SHA-256) as KiCad embedded files.
- Rebuilds `KiCadPcb.new()` through the object model: the standard layer set is
  composed from `Layer` objects and the default `setup` block from an
  S-expression builder, replacing the previous hard-coded template string.
- Models the schematic `(embedded_files)` block so embedded worksheets, fonts,
  and models survive a parse/serialize round-trip instead of being dropped.
- Adds `KICAD_PAGE_SIZES`, `KICAD_PAGE_DIMENSIONS_MM`, and
  `kicad_page_size_label` as the single source of truth for schematic page
  sizes that any caller can read.
- Carries forward the public R2 corpus archive restore path so release CI uses
  `artifacts.wavenumber.net` instead of Git LFS for the test corpus archive.
