Architecture

KiCad Cruncher owns public KiCad workflow commands and generated artifact layouts. It composes `kicad-monkey` parsing/rendering primitives and `wn-geometer` projection support without taking ownership of either package's lower-level contracts.

Boundaries

  • src/rs/kicad-cruncher-cli is the migration home of the canonical pure-Rust executable and owns native command dispatch and workflow artifact orchestration.
  • _cli.py owns top-level CLI registration and dispatch.
  • kicad_cruncher_cmd_* modules own individual public commands.
  • bom_pnp_* modules own shared BOM, PnP, and JLC normalization.
  • kicad_cruncher_pcb_svg_* modules own configured SVG view composition.
  • kicad_cruncher_pcb_layer_step* modules own layer STEP generation.
  • docs/contracts/ owns command and config schemas.
  • docs/design/ owns durable command and interface design docs.

Pure-Rust CLI Migration

The current installed console script remains Python while the Rust executable is built and checked against it as an oracle. Design review is the first complete vertical slice. The Rust executable is promoted only after it reproduces the contracted bundle and installed behavior without a Python runtime.

Release Policy

Every public command must be represented in the command manifest, CLI design docs, contracts when applicable, and Rack-owned signoff tests. Generated outputs remain disposable unless promoted to explicit fixtures or contracts.
