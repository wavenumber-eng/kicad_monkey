# KiCad Cruncher 2026.8.31

Release version: `2026.8.31`

Date: 2026-08-31

This release requires `kicad-monkey>=2026.8.31`, ensuring public Cruncher
installations consume the accepted optimized Monkey S-expression lexer and
sparse projection implementation.

Cruncher's Python package retains a normal public dependency and does not
embed Monkey or a workspace path. Coordinated release automation publishes
and verifies Monkey first, then installs that exact public version while
validating and publishing Cruncher.

The complete native Speedy design-review median improved from 7.618 seconds
at the clean baseline to 5.028 seconds in the final matched run. All 35 report
artifacts and all 29 schematic/PCB SVGs retained semantic parity, and the
reviewed Speedy source tree remained unchanged.
