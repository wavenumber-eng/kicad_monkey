# KiCad Cruncher 2026-06-25

Release version: `2026.6.25`

Date: 2026-06-25

## Highlights

- Updates the controlled `kicad-monkey` runtime dependency to
  `kicad-monkey==2026.6.25` for the object-model new-project assembly API.
- Adds the `project` command with a `create` subcommand that scaffolds a KiCad
  project from command-line flags, a JSONC `--config`, or an interactive
  `--tui` form, with all KiCad construction owned by `kicad-monkey` and the
  cruncher only gathering input.
- Fixes `health` double-counting genuinely-missing 3D models. The same missing
  model file is now reported once per distinct file with every reference site
  listed under it, so registering the `project-lib` generated `local-library`
  no longer inflates `missing_or_unresolved_model`.
- Keeps `wn-geometer==2026.6.10`.

## Compatibility

The `health` report keeps its `kicad_cruncher.project_health.a0` schema; missing
3D model issues are now grouped by unique model file and each carries a
`references` list of the places it is used, so consumers that summed per-file
issue counts no longer see inflated totals after `project-lib`.

The `project create` command depends on the `kicad-monkey` object-model
new-project assembly API, which ships in `kicad-monkey==2026.6.25`; the
controlled pin is bumped to that release accordingly.
