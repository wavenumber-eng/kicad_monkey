# KiCad Cruncher 2026.8.11.1

Release version: `2026.8.11.1`

Date: 2026-08-11

This patch release makes Altium footprint cleanup follow the WN library import
policy without synthesizing fabrication geometry.

## Highlights

- Use Monkey's import-specific footprint cleanup entry point after exact asset
  selection.
- Continue mandatory unsafe-pad normalization while removing imported Fab/User
  content without STEP projection or convex-hull fallback.
- Apply the canonical one-STEP model policy and warn when unsupported embedded
  model payloads are dropped.

## Compatibility

This release requires `kicad-monkey>=2026.8.11.1`.

## Validation

- Public workflow coverage verifies the importer calls import cleanup and never
  the full Fab-generating footprint filter.
- Coordinated Monkey/Cruncher cross-package gates and universal-wheel checks.

## Prior release: 2026.8.11

Release version: `2026.8.11`

Date: 2026-08-11

This release adds a public transactional executor for converting one exact
Altium symbol or footprint asset with KiCad CLI.

## Highlights

- Accept model-free typed requests with explicit source libraries, exact native
  keys, destinations, asset kinds, cleanup choices, and reuse/replace policies.
- Select exact converted assets, apply mandatory footprint normalization even
  when discretionary cleanup is disabled, and report ordered stage outcomes.
- Validate staged outputs with KiCad CLI and publish atomically only after every
  required stage succeeds.
- Preserve existing destinations on conversion, selection, filtering,
  validation, and publication failures.
- Produce a universal pure-Python wheel and validate the full suite on Python
  3.14 under Windows and Linux CI.

## Compatibility

This release requires `kicad-monkey>=2026.8.11`. Application data models,
provenance, and persistence remain downstream concerns.

## Validation

- Public L3 workflow tests for exact symbol/footprint selection, mandatory
  normalization, reuse validation, and failure preservation.
- Real KiCad 10.0.5 conversion and validation smoke test against a public WN
  Altium footprint library sample.
- Cruncher Rack, release-signoff, interface-design, build, and Twine gates.
