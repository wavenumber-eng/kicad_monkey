# KiCad Cruncher 2026-08-09

Release version: `2026.8.9`

Date: 2026-08-09

## Highlights

- Moves active KiCad Cruncher development into the public `kicad_monkey`
  monorepo while retaining the independent `kicad-cruncher` PyPI distribution,
  import package, and `kicad-cruncher` and `kcr` commands.
- Updates the controlled dependency floor to `kicad-monkey>=2026.8.9`, which
  provides the compiled schematic graph, Plotter IR, and inherited sheet-policy
  baseline.
- Adds source and clean-wheel compatibility gates that validate Monkey and
  Cruncher together without bundling either package into the other.

## Compatibility

The public CLI and Python import names are unchanged. Ordinary installations
continue to resolve `kicad-monkey` from public package metadata. A shared source
checkout is used only for monorepo development and CI.

## Validation

Release signoff covers Monkey and Cruncher package-local Rack gates, live-source
CLI behavior, package-specific wheel and sdist contents, Twine checks, and an
isolated installation of both locally built wheels.
