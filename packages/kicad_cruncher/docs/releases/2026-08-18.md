# KiCad Cruncher 2026.8.18

Release version: `2026.8.18`

Date: 2026-08-18

This release promotes the bounded native-backed Windows x64 design-review and
PCB physical-rendering paths while retaining Cruncher's Python orchestration
and presentation layer.

## Highlights

- Select the packaged `kicad-monkey-native` provider for compiled schematic
  graphs, version-E netlists, and PCB physical-base SVG on Windows x64 without
  retrying a Python implementation after native failure.
- Preserve the public `kicad-cruncher`, `kcr`, and module entry points and the
  `design`, `design-review`, and `dr` aliases with strict manifests, exact
  artifacts, output channels, and exit statuses.
- Publish design-review and `pcb-svg` artifact trees transactionally. Failed
  native rendering leaves a new destination absent and an existing destination
  unchanged; `pcb-svg` still intentionally authors a missing project-adjacent
  config template before rendering.

## Compatibility

This release requires `kicad-monkey>=2026.8.18`. The promoted production
native path is Windows x64. Linux and macOS retain the Python providers.
`KICAD_CRUNCHER_NATIVE_DESIGN_FACTS=1` and
`KICAD_CRUNCHER_NATIVE_PHYSICAL=1` are development/test opt-ins on other
platforms, not production-support declarations.

## Validation

- Exact native graph and version-E netlist parity across four governed
  multi-file KiCad projects.
- Native PCB provider coverage for enrichment, drill ordering, layer and mask
  selection, resource ceilings, no-fallback failures, and transactions.
- Isolated source-built Monkey and Cruncher wheel installation exercising the
  public design aliases, installed native provenance, exact artifact trees,
  hostile failures, and `pcb-svg` output.
