# KiCad Cruncher 2026-06-18

Release version: `2026.6.18`

Date: 2026-06-18

## Highlights

- Updates the controlled `kicad-monkey` runtime dependency to
  `kicad-monkey==2026.6.18`.
- Releases the project-local library extraction, cleaned library extraction,
  project health, and Megamaid project dissection workflows against the public
  targeted object extraction APIs.
- Documents the `library_extraction.json` metadata contract for raw parameter
  maps, canonical field maps, source paths, diagnostics, and extraction mode.
- Improves long-running command status output for library extraction,
  embedded asset extraction, design review, and PCB SVG generation steps.
- Keeps `wn-geometer==2026.6.10`.

## Compatibility

Existing design-review, BOM/PnP/JLC, PCB SVG, KiCad helper, and plugin commands
keep their invocation contracts. `health` and `megamaid` remain
non-destructive. `project-lib` continues to update project-local library table
entries by default and can opt out with `--no-update-library-tables`.
