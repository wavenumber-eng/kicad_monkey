# KiCad Cruncher 2026-07-30

Release version: `2026.7.30`

Date: 2026-07-30

## Highlights

- Updates the controlled `kicad-monkey` runtime dependency floor to
  `kicad-monkey>=2026.7.28` for project-local scan hardening, including KiCad
  `.history` and backup-folder hygiene.
- Adds explicit `project-lib` source relink dry-run/apply reporting for
  migrating schematic and PCB references to generated project-local symbol and
  footprint libraries.
- Hardens `project-lib --relink-sources` so placed schematic `lib_id` values,
  embedded schematic cache symbol names, direct cache unit names, schematic
  `Footprint` properties, PCB footprint links, and project library tables stay
  consistent.
- Adds `--repair-cache-links` for guarded placed `lib_name` cache repair when
  exactly one embedded cache candidate is available.

## KiCad Cache Validation

This release adds `cache_link_validation` and `cache_unit_validation` to
`source_relink.json`. Apply mode now blocks without writing source files when
unresolved cache-link or cache-unit issues remain.

The cache-unit validation mirrors KiCad's schematic loader behavior: a direct
child unit symbol under an embedded cache parent symbol must use the parent
symbol member name as its prefix and must retain the numeric unit/body-style
suffix. This catches invalid unit-name prefix failures that KiCad 10.0.5 can
surface in the GUI even when KiCad CLI export and ERC commands do not fail.

## Compatibility

Source relinking remains explicit through `--relink-dry-run` or
`--relink-sources`; the default `project-lib` extraction path does not rewrite
schematic or PCB sources. Apply mode rejects
`--relink-sources --no-update-library-tables` so generated local nicknames are
registered before source files point at them.

`wn-geometer` remains pinned at `2026.6.10`. Dev-std audit remains part of L99
release signoff and is release-blocking.
