# KiCad Cruncher 2026-07-16

Release version: `2026.7.16`

Date: 2026-07-16

## Highlights

- Updates the controlled `kicad-monkey` runtime dependency floor to
  `kicad-monkey>=2026.7.16`, consuming the public KiCad Monkey release that
  added the documented IR contract and public issue fixes.
- Migrates the public command manifest to `wn_dev_std.command_manifest.a0`.
- Expands release signoff to include dev-std `docs.cli`, `docs.plans`,
  `docs.requirements`, and `docs.release` governance scopes.
- Adds durable requirement records for release governance, publish
  authorization, CLI documentation, deferred daemon/plugin validation, future
  footprint HLR daemon work, schematic cleanup, PCB SVG selector follow-up, and
  library extraction hardening.
- Deletes closed active plan files from the release artifact path after moving
  durable obligations into requirements, design docs, release governance, and
  validation records.

## Compatibility

The public CLI command set is unchanged. The command manifest schema changes
from the previous project-local shape to the shared
`wn_dev_std.command_manifest.a0` governance contract, while the existing L99
signoff still verifies that parser help, README, CLI design docs, and the
manifest agree.

`kicad-monkey` is now expressed as a lower bound,
`kicad-monkey>=2026.7.16`, so compatible later public releases can satisfy the
runtime dependency. `wn-geometer` remains pinned at `2026.6.10`.
