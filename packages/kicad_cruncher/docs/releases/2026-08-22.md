# KiCad Cruncher 2026.8.22

Release version: `2026.8.22`

Date: 2026-08-22

This release publishes the completed native Windows x64 design-review CLI and
aligns Cruncher's controlled dependencies with the current WN CAD toolchain.
The PyPI package and normal `uv tool` installation remain the existing Python
Cruncher CLI on every platform.

## Highlights

- Ship pure-Rust `kicad-cruncher` and `kcr` Windows x64 executables for the
  complete design-review workflow, with the Python wheel retained as the full
  cross-platform command distribution.
- Require `kicad-monkey>=2026.8.22` and pin `wn-geometer==2026.8.21`, removing
  the resolver conflict with the current Altium Cruncher stack.
- Preserve bounded native graph, netlist, PCB physical rendering, source
  provenance, and transactional publication contracts.

## Platform behavior

On Windows x64, the Python CLI uses the native helper bundled in the Monkey
wheel for its established design-facts and physical-rendering provider paths.
Linux, macOS, and non-x64 systems retain the Python providers and do not require
that Windows executable. The standalone Rust CLI is a companion GitHub Release
artifact; it does not replace the PyPI-installed Python commands.

## Validation

The release gate validates the Python distributions, the exact commit-bound
native archive, isolated CLI aliases, reviewed-corpus outputs, public PyPI
Monkey installation, and a coordinated Monkey/Cruncher install without
workspace paths.
