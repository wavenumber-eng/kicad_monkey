# KiCad Cruncher 2026.9.2

Release version: `2026.9.2`

Date: 2026-09-02

This release requires `kicad-monkey>=2026.9.2`, ensuring installed Cruncher
workflows use the corrected browser-scale direct Rust SVG implementation.
Native design-review schematic and PCB composition consumes the typed renderer
artifact, including exact viewport metadata and ordinary renderer warnings,
without applying a second coordinate conversion.

Production-path tests generate actual Cruncher schematic and PCB review SVGs,
open them in Chromium, and verify visible unclipped paint, millimetre root
dimensions, matching view boxes, and clean browser logs. The coordinated
release retains context-controlled colors and styles, the public Python
dependency boundary, and the separately packaged native Rust CLI.
