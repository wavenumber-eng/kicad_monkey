# KiCad Cruncher 2026-07-17

Release version: `2026.7.17`

Date: 2026-07-17

## Highlights

- Updates the controlled `kicad-monkey` runtime dependency floor to
  `kicad-monkey>=2026.7.17`, consuming the public KiCad Monkey parser and
  rendering performance release.
- Improves `design`, `design-review`, and `dr` large-board behavior by reusing
  command-scoped PCB render state while writing per-copper-layer review SVGs.
- Preserves the existing full design-review output contract: design JSON,
  netlist JSON, KiCad S-expression netlist, schematic SVGs, PCB review SVGs,
  manifest, and README remain part of the bundle.
- Adds direct-vs-cached SVG parity coverage for styled output, root viewBox,
  width, height, enriched metadata, and drill/slot record counts.
- Records the remaining `KiCadDesign.to_json()` materialization cost as
  upstream `kicad-monkey` follow-up work instead of silently replacing full
  design JSON with partial or projection-backed output.

## Performance Evidence

Public-corpus all-copper-layer timing in the release-candidate research
harness showed the PCB review SVG loop improving from `10.170s` to `7.336s`
on 4-ch-backplane's four copper layers, and from `21.739s` to `6.700s` on
Speedy Processing Module's ten copper layers. SVG byte totals and drill/slot
counts matched in both runs.

The total command impact depends on the project and layer count. Full design
JSON generation remains part of the public command contract and can still
dominate low-layer or cached-render cases.

## Compatibility

The public CLI command set and design-review artifact contract are unchanged.
The PCB render cache is scoped to one command invocation and is not shared
across daemon, plugin, process, or mutable-board lifetimes.

`wn-geometer` remains pinned at `2026.6.10`. Dev-std audit remains part of L99
release signoff and is release-blocking.
