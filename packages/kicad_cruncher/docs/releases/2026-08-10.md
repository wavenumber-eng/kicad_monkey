# KiCad Cruncher 2026.8.10

Release version: `2026.8.10`

Date: 2026-08-10

## Highlights

- Adds the exact standalone compiled schematic graph to `design`,
  `design-review`, `dr`, and the nested Megamaid design-review bundle.
- Embeds page-scoped graph navigation indexes in every schematic SVG and
  validates all advertised selectors before bundle success.
- Enables an agent to traverse SVG object to terminal, local net, connected
  terminals and components, and back to rendered objects without name or
  geometry joins.
- Keeps optional legacy Design JSON indexes controlled by `--no-indexes` while
  retaining the authoritative compiled graph and SVG linkage.

## Compatibility

The public `kicad-cruncher`, `kcr`, and Python entry points are unchanged.
This release requires `kicad-monkey>=2026.8.10` and is published only after the
coordinated workflow verifies that exact Monkey version from PyPI.

## Validation

Release signoff covers the full Cruncher Rack suite, live workspace Monkey,
clean installed Monkey and Cruncher wheels, Linux and Windows CI, package
contents, Twine, and upgrade/rollback rehearsal.
