# KiCad Cruncher 2026-06-15

Release version: `2026.6.15`

Date: 2026-06-15

## Highlights

- Updates the controlled `kicad-monkey` runtime dependency to
  `kicad-monkey==2026.6.15`.
- Adds `project-lib` for metadata-preserving KiCad project-local library
  extraction and local `sym-lib-table` / `fp-lib-table` entry management.
  Generated symbol and footprint library folders default to the `.kicad_pro`
  stem, with command-line overrides for folder names and library nicknames.
  Schematic symbols stay project-local while footprints are deduped by footprint
  library link to reusable common footprint bodies. Optional project-local model
  export preserves embedded STEP/STP filenames instead of collapsing aliases by
  payload hash.
- Adds `lib-extract` and `library-extract` aliases for cleaned
  library-ingestion bundles while preserving `megamaid` as the compatibility
  command.
- Adds `health` for non-destructive project asset and 3D model
  diagnostics.
- Improves generated health README output with issue-kind counts and
  representative examples.
- Keeps `wn-geometer==2026.6.10`.

## Compatibility

Existing design-review, BOM/PnP/JLC, PCB SVG, KiCad helper, and plugin commands
keep their invocation contracts. `megamaid` and `health` do not mutate source
projects. `project-lib` now updates project-local library table entries by
default and can opt out with `--no-update-library-tables`.
