# KiCad Cruncher 2026-06-15

Release version: `2026.6.15`

Date: 2026-06-15

## Highlights

- Updates the controlled `kicad-monkey` runtime dependency to
  `kicad-monkey==2026.6.15`.
- Adds `project-lib` for metadata-preserving KiCad project-local library
  extraction.
- Adds `lib-extract` and `library-extract` aliases for cleaned
  library-ingestion bundles while preserving `megamaid` as the compatibility
  command.
- Adds `health` for non-destructive project asset and 3D model
  diagnostics.
- Improves generated health README output with issue-kind counts and
  representative examples.
- Keeps `wn-geometer==2026.6.10`.

## Compatibility

Existing design-review, BOM/PnP/JLC, PCB SVG, KiCad helper, and plugin commands
keep their invocation contracts. The new library and health commands are
additive and do not mutate source projects.
