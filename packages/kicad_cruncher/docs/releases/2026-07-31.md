# KiCad Cruncher 2026-07-31 Patch 1

Release version: `2026.7.31.1`

Date: 2026-07-31

## Highlights

- Fixes `project-lib --relink-sources --repair-cache-links` so referenced
  embedded schematic cache `Footprint` defaults are synchronized with the
  generated project-local symbol library definitions.
- Adds cache-body validation to `source_relink.json` beside the existing
  cache-link and cache-unit checks.
- Adds a KiCad CLI before/after ERC hygiene gate for project-lib apply mode
  when `--validate-kicad-cli` is used.
- Makes the ERC hygiene gate fail closed when `kicad-cli` fails, including
  deleting stale ERC JSON before each run.
