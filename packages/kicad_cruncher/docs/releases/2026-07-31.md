# KiCad Cruncher 2026-07-31

Release version: `2026.7.31`

Date: 2026-07-31

## Highlights

- Fixes `project-lib --relink-sources --repair-cache-links` for placed
  schematic symbols that carry a KiCad `lib_name` cache alias when the original
  `lib_id` is not directly present in the generated symbol relink map.
- Keeps generated project-local libraries reproducible for designs that include
  suffixed embedded-cache symbol members, such as imported or normalized symbol
  names.

## Validation

This release adds focused L0 regression coverage for member-only cache aliases.
The relinker now falls back to the mapped `lib_name` member when it can safely
localize the placed symbol `lib_id`, avoiding mixed external/local schematic
links after apply mode.

## Compatibility

This is a targeted hardening release for the `project-lib` relink workflow. The
public CLI shape and controlled runtime dependencies remain unchanged from
`2026.7.30`.
