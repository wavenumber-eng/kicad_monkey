Public command

project-lib

Extract metadata-preserving KiCad project-local library artifacts for inspection and future relinking workflows.

Usage

kicad-cruncher project-lib project.kicad_pro -o output/project-lib
kicad-cruncher project-library project.kicad_pro --no-asset-scan
kicad-cruncher project-local-lib project.kicad_pro --validate-kicad-cli

Arguments

file accepts a .kicad_pro project. If omitted, the command auto-detects exactly one .kicad_pro in the current directory.

-o selects the output directory. Without -o, artifacts are written under ./output/project-lib/. project-library, project-local-lib, and local-library are aliases for the same command.

The command always uses project-local extraction mode: metadata and per-instance footprint details are preserved so engineers can inspect local library candidates before future library-table or schematic/PCB relinking work.

--no-embed-models disables board-embedded model payload rehydration. --no-embed-external-models disables resolving external STEP/STP model paths into extracted footprints. --all-embedded-models scans the whole project and writes every embedded STEP/STP payload. --no-asset-scan omits the expensive full model-reference scan from the metadata JSON. --validate-kicad-cli asks KiCad CLI to parse/upgrade the generated libraries, and --kicad-cli selects the executable.

Ownership

The KiCad parsing, metadata preservation, model path classification, external STEP/STP embedding, metadata bundle construction, and KiCad CLI validation helpers are owned by kicad-monkey. kicad-cruncher owns command-line ergonomics, output directory layout, manifest writing, README writing, logging, and exit status.

The command is non-destructive. It does not edit the source project, update sym-lib-table or fp-lib-table, relink schematic symbols, relink PCB footprints, or rewrite project text variables.

Output

The selected output directory contains a self-contained project-local library bundle:

  • symbols/*.kicad_sym: metadata-preserving single-symbol KiCad symbol library files.
  • footprints.pretty/*.kicad_mod: metadata-preserving standalone KiCad footprints.
  • models/*.{step,stp}: decoded embedded STEP/STP model payloads required by the extracted footprint records, or every embedded payload when --all-embedded-models is used.
  • library_extraction.json: kicad_monkey.library_extraction_bundle.v1 metadata with raw fields, canonical identity fields, source paths, source references, model-reference diagnostics, and optional project asset scan.
  • project_lib_manifest.json: kicad_cruncher.project_lib_manifest.v0 artifact index with counts, relative output paths, mode, source project, and optional KiCad CLI validation results.
  • README.md: short human-readable summary for agents and reviewers.

megamaid handles cleaned lib_cruncher ingestion assets. project-lib handles metadata-preserving project-local assets.
