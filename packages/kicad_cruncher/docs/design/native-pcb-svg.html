Native PCB SVG foundation

The native pcb-svg and toon command adapters are under development and are not registered yet. Their shared Rust infrastructure retains one typed, source-bound board plotter artifact. Physical rendering uses kicad-monkey-svg directly; equal viewport and presentation requests reuse the completed artifact. Layer geometry remains available through the typed plotter document rather than being recovered from serialized SVG.

Configuration authority

src/tsp/kicad_cruncher/main.tsp governs the existing kicad_cruncher.pcb_svg.config.a0 shape. From the repository root, run node packages/kicad_cruncher/scripts/generate-svg-contracts.mjs to generate JSON Schema, TypeScript editor types and Rust data types; append --check to detect stale artifacts. Open style extensions and authored presence are retained: an omitted property, an empty list/object, and explicit null where allowed remain distinct.

Generated Rust types represent data; Serde decoding alone does not enforce all JSON Schema constraints. Runtime schema validation must precede native config decoding and merging before either command adapter is exposed. This foundation does not yet provide an accepted native config-loading boundary.

Models and fitting

Native commands support embedded models only. This intentionally differs from the existing Python SVG command's external STEP lookup. The reader uses public owner-scoped Monkey APIs, handles all visible attachments, decodes and hashes a resource once, and shares equal model content. External references, unsupported embedded extensions and failed payloads produce named diagnostics.

PCB Autodoc's geometry-based designator fitter is the authority for the coming Rust fitting module. Altium Cruncher is a secondary integration reference. Both commands will use the same fitter and virtual layer providers.

Current checks and remaining integration

Focused checks cover physical artifact reuse versus side/style changes, config extension and presence preservation, and embedded-only diagnostics. The retained Python SVG command now defaults to fast HLR detail and fast mesh shadow.

Native Geometer dependencies/discovery, complete config validation, remaining virtual layers, the Autodoc fitter, command dispatch and visual acceptance are still required. No native Toon availability or release is claimed by this slice.
